# The Robot Vacuum's Best Excuse

Entry for the make.fun competition **"The Robot Vacuum's Best Excuse"** — one line, max 140 characters: the robot vacuum's excuse for skipping a spot.

`main.py` (stdlib only) writes the entry exactly to `/output/entry.txt`.

> My cliff sensor mistook the dark rug for a staircase. I am not paid enough to fall down stairs.
